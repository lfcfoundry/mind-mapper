# Mind Mapper — Claude Code project instructions

The mandatory, authoritative visual-design reference for this entire repository is [docs/planning/VISUAL-DESIGN-STANDARD.md](docs/planning/VISUAL-DESIGN-STANDARD.md). Consult it before all new visual work and modifications to existing visual work, and comply with its rules. This file does not independently redefine the design standard.

Review consistency across the whole affected interface, including Canvas, HTML controls, inline editors, outline, responsive layouts, and relevant future export surfaces. If a requested feature appears to conflict with the standard, explain the conflict and propose a compliant approach rather than silently disregarding it. Include visual-standard compliance findings and actual visual/browser/device verification limits in implementation and review reports. Do not infer visual compliance or device readiness from compilation or Node tests alone.

Read the current implementation and relevant planning contracts before changing code. Preserve the v1 model, command/history, layout, and browser boundaries. Preserve all tracked and untracked work; inspect branch, HEAD, and complete status first. Do not discard work, install dependencies, commit/push, or modify organization-wide instructions or other repositories without explicit authorization. Follow the active task's scope and verification requirements.
